# EduEllen website assets

Place image files here before deploying:

| File | Description |
|---|---|
| `eduellen-hero-illustration.webp` | Hero section illustration (globe, map, books, charts) |
| `geography-card.webp` | Geography subject card image |
| `business-card.webp` | Business subject card image |
| `resource-placeholder.webp` | Default resource card image |
| `ellen-portrait-placeholder.webp` | Ellen's portrait (confirm permission before use) |
| `favicon.ico` | Site favicon |
| `apple-touch-icon.png` | iOS home screen icon (180×180px) |
| `og-image.jpg` | Social share image (1200×630px) |

Images should be provided in WebP format with appropriate fallbacks.
Use AVIF where possible for further savings.
Lazy-load everything below the fold (already set via `loading="lazy"` in the HTML).
